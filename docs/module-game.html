game

Hiking Survival — core game module.

All exported functions are pure: given the same arguments they always return the same value and produce no observable side‑effects. The UI layer (app.js) must not implement any game logic; it should only call these functions, render the returned state, and display the returned event log.

(static) campAndRest(state) → {ActionResult}

Description:

  • Rest at the current location to recover Stamina and Warmth at the cost of increased Hunger.

    Recovery: +30 Stamina · +20 Warmth · −15 Hunger. Stats cannot exceed 100 or drop below 0.

    Has no effect when the game is not in the 'playing' status, or when the player is not currently standing on a camp node.

(static) moveForward(state) → {ActionResult}

Description:

  • Advance the player one step along the trail, applying the base movement cost, terrain effects, and a deterministic random event.

    Has no effect and returns the original state when the game is not in the 'playing' status, or when the player is already at the final node.

    Base cost per move: −7 Stamina · −4 Hunger · −4 Warmth. Additional costs depend on the terrain type and any active random event.

(static) useItem(state, index) → {ActionResult}

Description:

  • Use an item from the player's backpack by its index in the inventory array. The item is permanently removed from the inventory after use.

    • Stamina / hunger / warmth items restore the corresponding stat immediately.
    • Gear items (e.g. Crampons) are equipped permanently and reduce terrain penalties for the rest of the run.
    • Camp items (e.g. Bivouac Tent) can only be used during Camp & Rest; calling this function with a camp item returns an explanatory event and leaves the state unchanged.

    Has no effect when the game is not in the 'playing' status, or when the index is out of range.
